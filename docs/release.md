# 公开发行门槛

0.2.0 已实现统一安装、离线迁移与模块控制，源码采用 0BSD 许可证，可作为开发预览项目公开。下表中的真实系统集成检查是面向普通用户正式发行的剩余事项，不作为公开开发源码的前置条件。生产尚未切换。

| 项目 | 当前情况 | 公开前剩余要求 |
|---|---|---|
| 隐私边界 | 本机资料和模拟产物留在仓库外；`docs/images/` 是仓库内唯一的二进制内容，为本机界面截图，图中账号名与积分读数已确认不敏感 | 检查最终文件与 Git 历史 |
| 许可 | 源码采用 0BSD；图标不随公开源码收录，安装时显式提供 | 引入第三方代码或素材时另核实其许可，0BSD 不覆盖客户端素材 |
| 统一安装 | 白名单生成单 MCP 插件，不含旧 Hook/巡检 | 真实客户端扫描识别及新用户安装检查 |
| 后台授权 | 模块独立，后台、自启动、自动重启默认关闭 | 真实 launchd 注册、停用与登录行为检查 |
| 完整停用 | stop 保存停用状态并撤下相应作业；repair 不启用 | 真实页面清理和守护优雅退出检查 |
| 应用重启 | 独立选择、禁止强杀，无法证明安全则延后 | 无任务环境实测重启与冷却；不能把模拟当真实检查 |
| 配置路径 | 统一 dataDir、进程 Node 路径、结构化 plist | 自定义路径与真实 launchd 环境检查 |
| 注入安全 | 只匹配 app://，不回退任意 page | 应用升级后接口和 DOM 检查 |
| 状态迁移 | 同一配置目录离线迁移；状态字节保留，损坏拒绝 | 经用户授权的实际离线迁移与回退 |
| 验收范围 | 规则模拟、系统依赖模拟与隔离安装测试 | 真实周期边界、真实客户端控制不在本轮重跑 |

旧控制文件保留供溯源，不进入统一包，也不代表新运行策略。停止旧积分守护本身可能取消自动恢复资格；安装器保留迁移时的状态，不制造新的恢复权。

公开前检查差异、未跟踪文件和历史；静态扫描不能证明不存在全部秘密。不得上传外层 local/、真实配置、日志、会话状态或应用提取物。
